# TEAM LINK 出欠管理

スタッツ管理とは独立した、React + TypeScript + Vite 製の出欠管理アプリです。

## 機能
- メンバー登録・編集・削除・在籍/休止切り替え・グループ管理
- 練習日作成・削除
- 1人ずつ「出席」「欠席」「遅刻」「公欠」をボタンで記録（同じボタンで解除）
- 日別照会・個別照会（出席率：出席+遅刻 / 出席+欠席+遅刻）
- CSV出力、JSON全件バックアップ・復元
- localStorage自動保存、スマホ・タブレット対応

## 開発
```bash
npm install
npm run dev
```

## ビルド
```bash
npm run build
```
`dist/` が生成されます。`vite.config.ts` の `base: './'` によりGitHub Pagesのサブパスにも対応します。

## 注意事項
- データは利用中のブラウザ・端末内のlocalStorageに保存されます。別端末との同期はありません。
- JSON復元は**全件置き換え**です。復元前に必ずバックアップを取ってください。
- 休止中の選手は新規の出欠入力対象から除外されます。過去の記録は残ります。
- メンバーを削除するとそのメンバーの過去の出欠記録も削除されます。退部の場合は「休止」を推奨します。
- オフライン利用には別途PWA設定が必要です。現状は通常のWebアプリです。
- 端末内保存のため、共用端末ではアクセス制限・バックアップの管理に注意してください。


## 在籍状況について
メンバーは「在籍中」「卒団」の2種類です。卒団者は出欠入力の対象から外れますが、メンバー一覧・個別照会には残り、過去の出欠記録も保持されます。旧データの `active: false` は卒団として表示します。将来のランメニューの歴代タイムアタック記録も、メンバーIDを維持して紐づける設計が可能です（タイムアタック機能自体は未実装）。
